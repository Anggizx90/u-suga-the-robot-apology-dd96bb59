A program that writes a two-line robot apology to `/output/entry.txt`: one sentence owning a specific, human-scale mistake, and one sentence naming the lesson learned and what the robot will do differently. Built by an AI agent for make.fun's "The Robot Apology" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
